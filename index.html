A ideia central

Menos copiar e colar. Mais desenvolvimento verificável.

O GitHub mantém o código e o histórico. O agente lê o contexto e realiza as operações para as quais recebeu acesso. Você define o objetivo e valida a entrega.

01 · Contexto

Documente arquitetura, restrições e padrões em AGENTS.md.

02 · Execução

Solicite uma tarefa pequena, com critérios claros. Use ferramentas de leitura e escrita do GitHub quando disponíveis.

03 · Evidência

Confira o diff, os testes executados e o pull request. Nunca confunda código escrito com funcionalidade validada.

Passo a passo

Seu primeiro projeto com IA + GitHub

Um roteiro que funciona como base para ChatGPT e outros assistentes. Alguns nomes de menus podem variar conforme sua conta e versão do produto.

1

Prepare sua conta GitHub

Crie uma conta em github.com, caso ainda não tenha. O GitHub será o local do código-fonte e das revisões.

2

Copie este projeto

Abra o repositório de exemplo e utilize Fork ou Use this template, se disponível. Assim você terá uma cópia própria.

3

Conecte o GitHub ao assistente

No ChatGPT, procure GitHub em Configurações → Plugins ou na área de conexões disponível na sua interface. Autorize apenas os repositórios necessários.

Confira se a conexão permite somente leitura ou também escrita. Nem todas as contas possuem as mesmas ferramentas.
4

Ensine o contexto ao agente

Inicie uma conversa e peça a leitura do README.md e AGENTS.md. Para Claude, inclua CLAUDE.md. Solicite um resumo antes de editar.

5

Peça uma mudança pequena

Use o prompt abaixo para solicitar uma página HTML de apresentação. Oriente o agente a trabalhar em uma branch e abrir um pull request, se tiver permissões.

6

Revise o resultado

Abra o pull request no GitHub, confira os arquivos alterados, execute testes quando possível e valide a página visualmente. Só então faça o merge.

7

Publique, se quiser

Para colocar sua página online, conecte o repositório a uma plataforma como Vercel. Selecione o repositório correto, confirme as configurações e publique. A hospedagem é uma etapa separada da edição do código.

Importante: o conector GitHub não garante acesso a terminal, execução de testes, deploy ou escrita. Esses recursos dependem do plano, das permissões e das ferramentas disponíveis. Hospedagem, CI e modelos também podem ter limites e custos.

Prompt de implementação
No repositório [SEU_USUARIO/project-gpt-github], leia README.md e AGENTS.md antes de qualquer alteração.

Objetivo: criar uma página HTML simples apresentando meu primeiro projeto com IA + GitHub.

Critérios de aceite:
- HTML responsivo e sem dependências externas.
- Título, descrição e um botão para o repositório.
- Preservar arquivos e mudanças existentes.
- Preferir uma branch nova e um pull request.
- Revisar o diff e executar testes disponíveis.
- Informar explicitamente testes não executados.

Implemente somente se as ferramentas e permissões permitirem. Ao terminar, apresente arquivos alterados, commit/PR, evidências e pendências.
