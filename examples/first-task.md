# Exercício 1 — Sua primeira alteração com IA

**Objetivo:** criar uma página HTML simples de apresentação em `examples/hello/index.html`.

Critérios de aceite:
- HTML sem dependências externas.
- Título "Meu primeiro projeto com IA + GitHub".
- Parágrafo explicando o fluxo de desenvolvimento.
- Layout responsivo e legível.

Peça ao assistente para ler AGENTS.md, implementar em branch e abrir PR. Revise o diff e abra o HTML em navegador para aceite visual. Se não houver navegador ou runtime disponível, marque o aceite visual como pendente.
