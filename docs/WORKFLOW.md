# Fluxo de trabalho — IA + GitHub

## 1. Preparar
Use um fork ou template. Configure acesso mínimo ao GitHub. Proteja a branch principal quando possível. Não armazene segredos no repositório.

## 2. Contextualizar
Informe repositório, branch, objetivo, comportamento atual, comportamento desejado, restrições e critérios de aceite. Peça leitura de AGENTS.md.

## 3. Implementar
Peça alterações pequenas. Para colaboração, prefira branch de feature e PR. Confirme quais ferramentas estão disponíveis: leitura, escrita, terminal, testes, CI e deploy são capacidades distintas.

## 4. Verificar
Confira arquivos modificados, diff, lint, testes, build e execução real quando aplicável. Ausência de ambiente é BLOCKED/SKIP, não PASS.

## 5. Revisar e aceitar
Revise mudanças e riscos. Faça merge após aprovação e evidência suficiente. Documente decisões que impactam o uso futuro.

## Checklist
- [ ] Repositório e branch corretos
- [ ] Instruções lidas
- [ ] Escopo e critérios de aceite claros
- [ ] Trabalho concorrente preservado
- [ ] Diff revisado
- [ ] Testes executados ou limitações registradas
- [ ] Nenhum segredo exposto
- [ ] Commit/PR identificável
- [ ] Aceite humano para mudanças críticas
