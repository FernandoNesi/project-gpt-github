# Project GPT + GitHub

**Aprenda a desenvolver software por conversa, com GitHub como fonte de verdade.**

Este repositório é um template educacional, independente de linguagem, para trabalhar com ChatGPT, Claude ou outros agentes com acesso autorizado ao GitHub.

## Comece aqui
1. Faça **Use this template** (se habilitado) ou um fork; não trabalhe diretamente neste repositório de exemplo.
2. Conecte sua conta GitHub ao assistente e autorize somente os repositórios necessários.
3. Peça ao assistente para ler `AGENTS.md`, `CLAUDE.md` (quando aplicável) e este README.
4. Descreva uma tarefa pequena, com resultado observável e critérios de aceite.
5. Prefira branch + pull request, revise o diff e execute os testes antes de mesclar.

> **Importante:** conectar o GitHub não garante edição de arquivos, execução de comandos, testes ou deploy. Essas operações dependem das ferramentas, permissões e ambiente disponíveis. Não declare testes como aprovados sem executá-los.

## Método
**Contexto → Plano curto → Implementação → Testes → Revisão → Commit/PR → Aceite.**

- GitHub guarda código, histórico e decisões versionadas.
- `AGENTS.md` contém instruções gerais para agentes.
- `CLAUDE.md` complementa as instruções para Claude.
- `docs/WORKFLOW.md` descreve o fluxo operacional.
- `docs/PROMPTS.md` oferece prompts copiáveis.
- `docs/SECURITY.md` estabelece controles de segurança.
- `examples/` contém um exercício inicial.

## Primeira tarefa sugerida
Peça: "Leia as instruções do repositório e implemente uma pequena página HTML que apresente o projeto. Crie uma branch, mostre o diff e abra um PR. Não afirme ter executado testes que não executou."

## Limites e custos
O uso de conectores, modelos, CI, hospedagem e ambientes de execução pode ter limites ou custos. A disponibilidade varia conforme plano, configuração e permissões.
